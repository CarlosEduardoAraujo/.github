## Tipo de Mudança

Marque com um `x` as opções que se aplicam:

- [ ] **Correção de bug (`fix`)**: alteração retrocompatível que corrige uma falha.
- [ ] **Nova funcionalidade (`feat`)**: alteração retrocompatível que adiciona um recurso.
- [ ] **Breaking change (`!`)**: correção ou recurso que altera o comportamento existente e exige adaptação.
- [ ] **Refatoração / Performance (`refactor` / `perf`)**: melhoria interna sem alterar a interface pública.
- [ ] **Documentação (`docs`)**: atualização apenas em arquivos de documentação, README ou comentários.

## Checklist antes do Merge

- [ ] Testei as alterações localmente e confirmei que não introduzem regressões.
- [ ] Atualizei a documentação correspondente (quando aplicável).
